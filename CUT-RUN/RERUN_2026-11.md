## The `@` path and HISAT2

The `hisat2` wrapper is Perl. The env's Perl config file has the `/projects/c832500103@colostate.edu` path written into it, and Perl reads `@colostate` as an array. HISAT2 then exits with code 255 after about 30 seconds and logs `Global symbol "@colostate" requires explicit package name`. Two fixes were needed:

1. Activate through the path without `@` (`PROJ=` above).
2. Escape the `@` inside the env, once. Redo this whenever `hisat2_env_fixed` is rebuilt:

```bash
F=/projects/.colostate.edu/c832500103/conda_envs/hisat2_env_fixed/lib/perl5/5.32/core_perl/Config_heavy.pl
cp $F $F.bak
sed -i 's/\([^\\]\)@colostate/\1\\@colostate/g' $F
```

Test with `perl -V` (it loads `Config_heavy.pl`). `perl -MConfig -e 1` passes even when the env is broken.

## Running Step 2.3 straight after 2.2

The SAM list for 02.3 can be built before the SAMs exist, from `FastqTrimmed.txt`, so 02.3 can be queued behind 02.2:

```bash
SAMDIR=<full path to 02.2_Cxt_HisatAligned_Cleaned>
sed "s|^|$SAMDIR/|; s|_R1_trimmed.fastq.gz\$|.sam|" FastqTrimmed.txt > $SAMDIR/sam_file_list.txt
sbatch --dependency=afterok:<hisat_jobid> --kill-on-invalid-dep=yes --array=1-96%20 02.3_runBam_array.sh
```

If any HISAT2 task fails, the dependent job is cancelled. Rerun that task, then resubmit.
